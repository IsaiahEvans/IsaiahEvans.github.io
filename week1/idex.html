HTML, CSS & JavaScript Webpage

A small single-page app built to practice the three core front-end languages together: HTML for structure, CSS for the design, and JavaScript to make the page respond to the user. The idea comes from my own work — before a car shoot I always write out a shot list, so I built one that runs in the browser.
